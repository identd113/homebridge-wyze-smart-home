# Release notes: homebridge-wyze-smart-home 2.0.0-beta.1

First 2.0 beta, published to npm on 2026-04-28 under the `beta` tag (`npm install homebridge-wyze-smart-home@beta`, or "Install Beta Version" in homebridge-config-ui-x). Stable users on `latest` were not affected. The tag is `v2.0.0-beta.1` (`76b41ef`).

**Pairs with:** `wyze-api@2.0.0-beta.1`.

The full list is in the `v2.0.0-beta.1` section of `CHANGELOG.md`. This page is the short version.

## What it is

- **Live HomeKit cameras**: a real camera tile with live video and audio, snapshots and per-camera switches (garage door, spotlight, floodlight, siren, notifications, motion detection). Uses the bundled `ffmpeg-static`.
- **New accessories**: `WyzeRoomSensor` (thermostat room sensors), `WyzeIrrigation` (Sprinkler Controller, one valve per zone), `WyzeVacuum` (fan for start/stop and suction, battery, optional per-room sweep switches).
- **Status instead of "No Response"**: every accessory reports `StatusActive` and `StatusFault` and keeps the last known state when Wyze is silent.
- **State persists across restarts** for every stateful accessory.
- **Config 2.0**: a nested config shape, migrated automatically on first start with a backup at `config.json.pre-2.0.bak`.
- **Security hardening**: log redaction on by default, `auth.secretsFile`, pinned base URLs, a redirect guard.
- New per-accessory options: thermostat `mode` (heat-only or cool-only), `thermostat.exposeRoomSensors`, `deviceTypeOverrides`.
- Devices added or verified: Cam V4, Battery Cam Pro, Cam Pan v3, Floodlight Pro, Cam OG and OG Telephoto 3x, Palm Lock, Robot Vacuum, Sprinkler Controller.

## Breaking changes

- **Cameras change from bridged to external accessories.** On first start the bridged copy is removed and each camera must be paired again in the Home app.
- The config is restructured (migrated automatically; keep the `.bak`).
- `homebridge-config-ui-x` moved to `devDependencies`, so installs no longer compile `node-pty`.
- `engines.homebridge` is `^1.6.0 || ^2.0.0` (this was wrong for Node 22 on Homebridge 1.x; corrected to `^1.8.5 || ^2.0.0` in beta.4) and `engines.node` is `^18.20.4 || ^20.15.1 || ^22.0.0 || ^24`.
- Logger format changed to the Homebridge style; `apiLogEnabled` maps to `logging.level: debug`.
- Unused dependencies removed (`aws-sdk`, `crypto-js`, `moment`, `urllib` and others), which cleared two critical advisories.

## Known gaps at release

- Production `npm audit` still showed 4 findings in the `werift` chain (fixed in beta.3).
